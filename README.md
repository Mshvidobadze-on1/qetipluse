# ⚡ QetiPluse (ქეთი პლუსი) — პრემიუმ ტექნიკის ჰაბი

თანამედროვე ქართული ტექნიკის ონლაინ მაღაზია (E-Commerce Web Application), აგებული **React 19 + TypeScript + Vite + Tailwind CSS v4** სტეკზე.

## ✨ ძირითადი ფუნქციონალი
- **9 კატეგორია და 48+ რეალური პროდუქტი**: მობილურები, დრონები (DJI), ტაბები, სმარტ საათები, ლეპტოპები | IT, აუდიო სისტემა, Gaming, TV | მონიტორები, ფოტო | ვიდეო.
- **ავტომატური 3D Arch Hero სლაიდშოუ**: უწყვეტი ავტომატური გადართვით, პროგრეს-ინდიკატორით და გამჭვირვალე (`.png` background-free) პროდუქტის სტუდიური ფოტოებით.
- **სულსწრაფი შეთავაზებები (Hot Offers)**: ჰორიზონტალური სწრაფი შეთავაზებების კარუსელი `e-SIM` და ფასდაკლების ბეიჯებით.
- **ქართული ბანკების ონლაინ განვადების კალკულატორი**: **TBC Bank**, **BOG ნაწილ-ნაწილ** და **Credo Bank** (3, 6, 12, 24 თვე — 0%-იანი განვადების დათვლით).
- **კალათა, სურვილების სია (Wishlist) და პროდუქტების შედარება (Compare)**: სრული ინტერაქტიული მოდალებით და შეკვეთის გაფორმებით.
- **Light / Dark რეჟიმი** და სწრაფი ძებნა (`⌘K` / `Ctrl+K`).
